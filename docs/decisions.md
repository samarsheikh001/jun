### D-13 — Slack implementation details
- Each self-hosted install needs its **own Slack app** (OAuth credentials can't be shared across installs). Plan: bundled app manifest + guided setup (T-13).

Free-plan orgs can only be invited to *try* Slack Connect temporarily. Fine for most B2B SaaS teams and customers, but customers who aren't on paid Slack need the widget/email instead.

- **2026-10-10 — D-42 — The model's decisions are tool calls, not control lines in its text.** The reply used to carry `HANDOFF: <reason>` (first line), `ESCALATE: <summary>` (last line) and `FOLLOWUPS: q | q`, found by parsing the text and held back from the stream while a line might become one. Workers AI's Mistral put `HANDOFF:` mid-reply ("I'm sorry, I can't do that for you. HANDOFF: …"): the visitor saw the internal line and nothing was handed off. The user asked for the proper fix rather than searching the text harder. Decided: `handoff({ reason })` and `flag_problem({ summary })` (offered only with debug context), read from the response's tool calls (`runAgent`, `replyOutcome` in `worker/ai/agent.ts`); the outcome shape is unchanged, so the Conversation object, evals and widget are too. Handoff has no `execute` (the call ends the turn, like a page action). Flagging runs, because Mistral doesn't reliably write text and call a tool in one response: the model flags first and explains in the next step, and a step that already explained ends the loop (otherwise Mistral wrote its whole reply again). Words written before a handoff stay as the AI's message, then the notice. Nothing is held back from the stream any more. `tools/<name>.yaml` can't take the built-in names. E2E on ChatGPT and Workers AI: chat, AI, debug, agent and page actions pass; no reply contains a control string. Follow-up questions were never produced in production with the old line (0 of 303 AI replies), and a `suggest_followups` tool wasn't called either (0 of 31 e2e replies, both providers); the user chose to have them written by a separate fast job instead (`followups`, AI-16's list): after an answer that used the knowledge is saved, one small call writes up to 3 questions from the question, the answer and its sources, and they're added to the message in place, a moment after the answer.
